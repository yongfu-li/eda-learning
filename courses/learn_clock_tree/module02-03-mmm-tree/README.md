After this module you can: **Build an MMM-style tree by merging closest fragments at midpoints.**

## Two tracks (pick one or both)

### Track A — Implement (hands-on)

1. Open [EXAMPLES.md](EXAMPLES.md) and implement **Method of Means and Medians (MMM) clock tree** on `examples/tiny_cts.json`.
2. Complete [CHECKLIST.md](CHECKLIST.md) with latency and skew when relevant.
3. Optional self-check: `./scripts/module.sh 02-03-mmm-tree --check` (from course root).

### Track B — Browser lab (online)

1. Local: [http://127.0.0.1:8080/tools/mmm-tree/](http://127.0.0.1:8080/tools/mmm-tree/)
2. Live: [https://universal-verification-methodology.github.io/learning/tools/mmm-tree/](https://universal-verification-methodology.github.io/learning/tools/mmm-tree/)
3. Tools shelf: open `mmm-tree` from the platform tools index
4. Load the **starter clock tree** instance, build a tree, inspect skew and buffers.
5. Check off Track B items in [CHECKLIST.md](CHECKLIST.md).

> Concept labs teach CTS literacy on a tiny chip — not production clock trees.
