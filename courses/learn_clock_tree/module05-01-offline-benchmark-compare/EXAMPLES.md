# Examples — Offline benchmark compare

## Platform benchmark (preferred)

Open [`platform/benchmarks/clock-tree/index.html`](../../../platform/benchmarks/clock-tree/index.html):

1. Preset **Hard** → **Run benchmark**.
2. Confirm **Zero-skew merge** or **Portfolio min-skew** ranks near the top on skew.
3. Click a scoreboard row to inspect the tree view.
4. **Example** → pick Recursive H-tree → **Load example** → **Register solver**.

## Local harness (optional)

Compare engines on `common/tiny_cts.json` with Track A solvers (see course `common/solvers.py`).
