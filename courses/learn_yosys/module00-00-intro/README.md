## What this course is

**learn_yosys** has three parts: **Part A** pass map on `tiny_yosys.json` (same pass names as Yosys), **Part B** real Yosys CLI/RTLIL evidence on `rtl/tiny_and_or.v` (`read_verilog` → `proc` → `flatten` → `opt` → `synth`), then **Part C** algorithms bound to real Yosys via `algo_solvers.py` + `partc_bind.py`. Links to [learn_synthesis](../learn_synthesis/README.md) for synthesis concepts.

**Prerequisite:** [learn_synthesis](../learn_synthesis/README.md) or synthesis literacy. **Next:** [learn_openroad](../learn_openroad/README.md).
