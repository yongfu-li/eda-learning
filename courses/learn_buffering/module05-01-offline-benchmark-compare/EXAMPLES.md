# Examples — Offline benchmark compare

## Platform benchmark (preferred)

Open [`platform/benchmarks/buffering/index.html`](../../../platform/benchmarks/buffering/index.html):

1. Preset **Hard** → **Run benchmark**.
2. Confirm **Candidate-site DP** or **Composite portfolio** ranks at/near the top (delay + slew).
3. Compare against plain Van Ginneken and wire-only.
4. **Example** → Candidate-site DP → **Load example** → **Register solver**.
