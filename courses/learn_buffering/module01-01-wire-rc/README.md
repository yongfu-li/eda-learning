### Track A — Implement (hands-on)

1. Open [EXAMPLES.md](EXAMPLES.md) and implement **wire R/C from length (r_per_unit, c_per_unit)** on `examples/tiny_buf.json`.
2. Complete [CHECKLIST.md](CHECKLIST.md).
3. Optional: `./scripts/module.sh 01-01-wire-rc --check`

### Track B — Browser lab (online)

1. Local: [http://127.0.0.1:8080/tools/wire-rc/](http://127.0.0.1:8080/tools/wire-rc/)
